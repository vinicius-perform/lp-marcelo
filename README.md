# Landing Page - Marcelo Vasconcelos

Landing page oficial de apresentação das mentorias **Do Plantão ao Milhão** e **Método MVX** pelo Dr. Marcelo Vasconcelos, voltadas para médicos, dentistas e donos de clínicas na área da saúde.

## 🚀 Tecnologias

- HTML5 semântico
- CSS3 moderno (Custom Properties, Flexbox, CSS Grid)
- JavaScript Vanilla (navegação responsiva, tracking de conversão, animações de scroll e seleção interativa dos métodos)
- Fontes: Fraunces & Instrument Sans (Google Fonts)

## 💻 Como executar localmente

Para visualizar a página localmente, você pode iniciar um servidor estático:

```bash
# Com Python 3
python3 -m http.server 3000
```

Em seguida, acesse [http://localhost:3000](http://localhost:3000) no seu navegador.
